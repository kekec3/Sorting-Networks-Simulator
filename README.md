# Sorting Networks Simulator

An interactive web-based simulator for **sorting networks**, designed to visualize their structure, execution, and parallelism.

The project was developed as a final-year thesis project at the **School of Electrical Engineering, University of Belgrade**.

## Overview

Sorting networks are fixed sequences of compare-and-swap operations whose structure is independent of the input data. This makes them particularly interesting for studying **parallel execution**, since independent comparators can be executed simultaneously.

This simulator provides an interactive way to explore that process instead of only viewing a static representation of a sorting network.

You can:

- Generate sorting networks using multiple algorithms
- Load known configurations for small network sizes
- Provide your own input values
- Execute the network step by step
- Move both forward and backward through the simulation
- Watch values move through the network
- Follow synchronized parallel pseudocode
- Visualize parallel processing elements
- Inspect network and execution statistics
- Compare networks generated by different algorithms

## Features

### Sorting Network Generation

The simulator supports three constructive network-generation algorithms:

- **Bitonic Sort**
- **Batcher's Odd-Even Merge**
- **Pairwise Sorting Network**

For small network sizes, the application can also load **known optimized network configurations**.

### Interactive Simulation

The execution of a sorting network can be explored at different levels of detail.

The simulator supports:

- Play/pause
- Adjustable simulation speed
- Step forward
- Step backward
- Reset
- Automatic playback
- Phase-by-phase execution
- Finer-grained micro-steps within a phase

The reverse functionality is implemented using snapshots of the array state, allowing previous stages of the simulation to be restored.

### Network Visualization

The sorting network is displayed using the standard comparator-network notation:

- Horizontal lines represent data wires
- Comparators connect pairs of wires
- Stages represent groups of independent comparators
- Values are displayed as animated tokens moving through the network

The visualization highlights the current stage while keeping completed and upcoming stages visually distinguishable.

### Parallel Execution Visualization

A major focus of the simulator is making the **parallel nature of sorting networks** visible.

The application provides a visual representation of processing elements used during each stage. This is synchronized with the network and pseudocode so that the user can see how independent comparators can be executed in parallel.

The displayed utilization represents the parallelism available in the simulated execution model; it is not a measurement of utilization of the user's physical GPU.

### Synchronized Pseudocode

The simulator displays pseudocode for the parallel execution model.

As the simulation progresses, the corresponding pseudocode instructions are highlighted, connecting:

**Network Structure → Pseudocode → Processing Elements → Data Movement**

This makes the relationship between the abstract sorting-network structure and its parallel execution easier to understand.

### Statistics

The application provides real-time information about the current network and simulation, including:

- Input size `N`
- Network depth
- Number of comparators
- Current stage
- Completed comparisons
- Number of swaps
- Parallel-resource utilization

This also makes it possible to compare different network-generation algorithms quantitatively.

## Supported Algorithms

| Algorithm | Description |
|---|---|
| **Bitonic Sort** | Recursive construction based on bitonic sequences and bitonic merging |
| **Odd-Even Merge** | Batcher's divide-and-conquer odd-even merging network |
| **Pairwise** | Comparator construction followed by greedy ASAP stage scheduling |

The simulator can demonstrate how different construction strategies can produce networks with different depths and numbers of comparators for the same input size.

## Example

For example, an 8-input Bitonic network can be generated and simulated with an arbitrary input sequence.

The user can then:

1. Inspect the generated network
2. Enter or generate input values
3. Execute the network one stage at a time
4. Observe individual comparisons and swaps
5. Follow the corresponding pseudocode
6. Observe the parallel processing elements
7. Inspect execution statistics
8. Replay or move backward through the simulation

The project also includes comparison scenarios for different network-generation algorithms and input sizes.

| Technology | Purpose |
|---|---|
| **Angular** | Application framework |
| **TypeScript** | Application logic and data modelling |

| **Angular Signals** | Reactive application state |
| **Node.js / npm** | Development environment and dependency management |

## Architecture

The application separates the sorting-network domain logic, simulation state, and presentation layer.

The main parts of the application include:

- **Network generation** — algorithms responsible for constructing sorting networks
- **Network state** — representation of wires, comparators, stages and network metadata
- **Simulation** — execution state, snapshots, stepping and playback
- **Visualization** — SVG representation of the network and moving values
- **UI components** — configuration, controls, pseudocode, parallel-execution visualization and statistics

The application uses Angular Signals as its central reactive state mechanism, allowing the different visualization components to remain synchronized with the current simulation state.

## Getting Started

### Prerequisites

Make sure you have:

- [Node.js](https://nodejs.org/)
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/kekec3/Sorting-Networks-Simulator.git
cd Sorting-Networks-Simulator
```

Install dependencies:

```bash
npm install
```

### Development Server

Start the Angular development server:

```bash
npm start
```

or:

```bash
ng serve
```

Then open:

```text
http://localhost:4200/
```

The application automatically reloads when source files are modified.

### Production Build

Create a production build with:

```bash
npm run build
```

The generated files are placed in the `dist/` directory.

### Tests

Run the unit tests with:

```bash
npm test
```

## Educational Purpose

The primary purpose of the simulator is to make the structure and execution of sorting networks easier to understand.

A static diagram can show which comparators exist, but it does not show how values move through the network or which operations can execute simultaneously. The simulator addresses this by combining animation, step-by-step execution, synchronized pseudocode, parallel-resource visualization, and statistics.

The project can therefore be used to explore concepts such as:

- Comparator networks
- Compare-and-swap operations
- Network depth
- Comparator count
- Parallel execution
- Data-independent algorithms
- Differences between sorting-network constructions

## Future Improvements

Possible extensions identified during development include:

- Allowing users to manually construct sorting networks
- Validating user-created networks
- Importing and exporting networks in JSON format
- Comparing multiple networks on the same input
- Adding more network-generation algorithms
- Providing a more concrete representation of parallel hardware execution

These additions would extend the simulator from demonstrating existing networks toward allowing users to design and analyze their own configurations.
